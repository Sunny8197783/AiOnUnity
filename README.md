# 경보 이전 (Before the Siren)

전쟁 직전의 준비가 전쟁 이후의 선택지를 바꾼다는 이야기 중심 민방위 대비 시뮬레이션입니다.
가상 동네 연무동에서 정민이 되어 사흘의 준비, 정전과 공습경보, 대피소 생활, 공식 대피까지를 겪습니다.
사재기가 아니라 **정보를 확인하고, 상황에 맞게 판단하고, 이웃과 함께 버티는** 법을 플레이로 익힙니다.

- 엔진: Unity **6000.3.22f1** (Unity 6.3), URP
- 원작: three.js 게임 safe-route를 Unity로 옮기고 확장했습니다.
- 화면에 적이나 폭력, 부상 장면은 나오지 않습니다. 동네·인물·회사·재난문자·방송은 모두 가상입니다.

## 이야기 구성

| 장 | 제목 | 내용 |
|---|---|---|
| 프롤로그 | 평소와 다른 화요일 | 확인된 사실, 추정, 소문을 나눕니다 |
| 1장 | 준비 | 여섯 칸의 시간으로 무엇을 준비할지 정합니다 |
| 2장 | 정전과 경보 | 불이 꺼지고 경보가 울립니다. 대피소 심폐소생술, 304호 어르신 시점 |
| 3장 | 버티기 | 정전과 단수, 복도 화재 앞 "살펴서 대피", 3D 소화기, 산에서 내려온 사람들 |
| 4장 | 남을까, 떠날까 | 조건이 바뀌면 답도 바뀝니다. 임시 거처의 하루 |
| 5장 | 공식 대피 | 가방 하나와 새로운 길 |
| 엔딩 | 생존 기록 | 13가지 결말, 학습 리포트 |

## 심사·수업용 진입

타이틀 화면에서 바로 고를 수 있습니다.

- **장면 바로가기**: 대표 장면 12개(22분, 공습경보와 계단, 대피소 심폐소생술, 304호 어르신, 소화기 쓰기, 임시 거처 등)를 처음부터 하지 않고 바로 시작합니다. 진행은 데모 저장에만 남고 이어하기는 바뀌지 않습니다.
- **교사용 30분 모드**: 수업 한 차시에 맞춘 경로입니다.
- **더 알아보기**: 기록관(실제 사건과 제도), 신고 번호 카드, 연무동 지도, 훈련 달력, 우리 집 안전 준비.

3분 시연 경로(정확한 클릭과 시간표)는 [Docs/COMPETITION_PLAN.md](Docs/COMPETITION_PLAN.md)의 "3분 시연 경로"에 있습니다.

## 실행하기

1. Unity Hub에서 이 폴더를 Unity 6000.3.22f1로 엽니다.
2. `Assets/_AiOn/Scenes/Boot.unity`를 열고 Play를 누릅니다.

### Windows 빌드

메뉴 **AiOn → Build → Windows Player**로 `Builds/Windows/`에 만들어집니다(약 1.2 GB, 저장소에는 포함하지 않음).
같은 편집기 세션에서 MCP 코드 실행을 쓴 뒤라면 스크립트를 한 번 다시 컴파일하고 빌드하세요.

### 테스트

Window → General → Test Runner → EditMode에서 전체 실행합니다. 현재 **1349개 모두 통과**합니다.
원작 대조(parity) 테스트가 장·체크포인트·사실 목록을 지킵니다.

## 사실과 출처 원칙

- 화면의 안전 문장은 모두 공식 출처가 있는 사실만 씁니다. 원작의 사실 95개는 `Assets/_AiOn/Data/Source/facts.json`, 새로 더한 사실은 출처 URL·확인일과 함께 `facts-ext.json`에 있습니다.
- 확인되지 않은 수치는 쓰지 않습니다. 예: 심폐소생술은 "약 5cm, 분당 100~120회, 30:2", 교대는 "지치기 전에 교대를 요청", 미상 낙하물 신고는 "군부대(주민신고 1338)나 가까운 경찰서", 급할 때 112, 화재·응급 119.

## 그래픽

- 사람: Microsoft Rocketbox 아바타 14명(MIT)을 Humanoid로 가져와 한국인 평균 키로 맞추고, 눈 깜박임·대사 입 모양·시선, 걸음 속도 보정, 어두운 장면용 인물 채움광을 넣었습니다.
- 환경: 트라이플래너 표면 디테일, 데칼, 사진 하늘, 방마다 창빛, 정전 실내 가독성, 불·연기 플립북.
- 미니게임: 심폐소생술·현관 판단·압력계·신고 카드 장면을 실시간 3D 세트로 그립니다.
